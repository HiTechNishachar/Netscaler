# NetScaler Support Bundle Example Directory Structures

This document provides a generalized, safe-for-public-viewing example of the directory structures commonly found in Citrix NetScaler, NetScaler Console (ADM), and Console Agent support bundles. 
All customer-specific identifiers, IP addresses, exact timestamps, and case numbers have been sanitized.
